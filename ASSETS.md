# Asset provenance

The original Windows-style SVG icons, hostel illustration, project schematic, Pinball table, and system WAVs were created for Room 404. The fourteen short system cues and twelve-second hostel instrumental are generated by `scripts/generate_media.py` and require no remote service. They are period-inspired originals, not recordings extracted from Microsoft Windows or commercial music.

The following images were extracted from the **user-supplied Gandhi Hackathon problem statement PDF**, using its embedded image streams, and converted to JPEG for the website. They were not found online or represented as original photography. Rights remain with their original rights holders; the supplied PDF did not include per-image author/license details.

The supplied filename `9-11-attack-planning.pdf` opens a generated historical classroom news clipping, containing a reference photograph and a fictional student note. Its source is `scripts/generate_media.py`; its local page preview is bundled alongside it. It contains no operational planning instructions.

`without_me_eminem.mp3` is a virtual collection catalog entry, not a bundled copy of the commercial recording. Its player labels the available original hostel loop. Counter-Strike and GTA III are reference folders, not emulated or redistributed commercial executables. Minesweeper, Solitaire, and Room 404 Pinball are original browser implementations.

Library and font credits are in README.md and the corresponding installed package licenses. Original input documents remain outside this application repository. Extracted reference image assets are now part of the local application at the user's request; no cloud publication was performed.
